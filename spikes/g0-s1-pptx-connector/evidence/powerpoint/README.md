## 前置

1. 一台装有 **Microsoft PowerPoint 2016 或 365** 的机器（Windows/macOS 均可）。
2. 把以下文件拷到该机器：
   - `spikes/g0-s1-pptx-connector/out/A-absorption.pptx` ← **主验证对象**
   - `spikes/g0-s1-pptx-connector/out/C-flat.pptx`（可选，对照）
3. **先确认你打开的是真 PowerPoint**：本机 WPS 会把自己伪装成 "Microsoft PowerPoint / 12.0"，
   所以不要靠"关于"对话框里的名字判断——直接确认 `POWERPNT.EXE` 存在，或确认 PowerPoint 是独立安装的。

---

## 步骤 1：打开是否报修复（对应 G1-d / G1-c）

双击打开 `A-absorption.pptx`。

- [ ] **没有**"PowerPoint 发现……中的内容有问题 / 需要修复"弹窗
- [ ] 如果出现弹窗：**不要点"修复"**，直接截图，然后点"取消"。这条本身就是关键证据。

> 预期：3 个基础形状（蓝条、红条、橙菱形）+ 1 条绿色折线 + 1 个含 2 个子条的组合。

**记录**：弹窗有无 = ？

---

## 步骤 2：拖动任务条，观察端点是否跟随（**G1-a，唯一有效判据**）

1. 单击**蓝色条**（`bar-a`）选中它。
2. 按住拖动，把它**上下左右移开一段距离**（例如往上移 2 cm、往右移 3 cm）。
3. **观察绿色折线**：
   - [ ] 折线的**起点仍贴在蓝条边缘**（而不是留在原地、或从条内部穿出）
   - [ ] 折线的**走向重新计算**（而不冻结成旧形状）
4. 对**红色条**（`bar-b`）重复步骤 2–3：
   - [ ] 折线**终点仍贴在红条边缘**并随之改道

> **这一步就是门禁 G1-a。** 请对每一步给出「通过 / 失败」。
> 若失败，请尽量描述失败形态（端点悬空？穿进形状内部？走线乱跳？连线被拉成直线？）。

**记录**：`bar-a` 拖动 = ？　`bar-b` 拖动 = ？

---

## 步骤 3：拖动组合，检查父子是否偏移（G1-c）

1. 单击下方**紫色条**（组合中的一个子形状）→ 应选中**整个组合**（含紫条与青条）。
2. 拖动整个组合到别处。
3. - [ ] 两个子条**保持彼此的相对位置**，没有错位、变形或一个动一个不动。

**记录**：组合拖动 = ？

---

## 步骤 4：保存并回传 XML（**极有价值**）

1. 另存为 `A-saved-by-powerpoint.pptx`（**不要覆盖原件**，原件要留作对照）。
2. 把该文件拷回本目录 `evidence/powerpoint/`。

> **为什么这一步价值最高**：PowerPoint 保存时会把 connector 重写成它认可的正确形态。
> 这份 diff 就是补丁器要生成的**权威目标形态**——比任何文档都可靠。
> 我们会在拿到后对比：它是否保留 `stCxn/endCxn`？`idx` 是否被改写？是否新增 `a:cxnSpLocks`？
> `xfrm` 的 `rot/flipH/flipV` 组合是什么？

**记录**：已回传文件 = ？
