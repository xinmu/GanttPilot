## 口径

- 页面 = `apps/web/dist` 的**打包产物**；**左表在场**（不带 `?table=0`，否则判据没有对手可比）；
- 每个位置：设 `pane.scrollTop` → `nextTick` + **两帧** → 读 `getBoundingClientRect()`；
- **只读**：不改文档、不派发指针事件、不进手势；采完把 `scrollTop` 复位 0；
- 行差 = `图表行顶 − 左表行顶`（**对齐时 = 0**；图表比左表高时为负）；
- 条形 x 判据 = DOM 条形左边 − (`paneLeft + xLeft − scrollLeft`)：守"所见 = 所点"的横向一半；
- 容差 = `THRESHOLDS.rowAlignTolerancePx` = **0.5 px**；
- 轴覆盖优先用**色带矩形**（无描边误差），无色带时退到网格线（含 ±0.5 px 描边）；
