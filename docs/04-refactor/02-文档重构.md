> 前置：[P1 的三条新检查](04-验收与门禁.md)必须先落地并**在现状上翻红**——否则本阶段改完仍会再次分叉。

## 一、目标分层

```
L0  入口（≤ 6 KB，唯一注入起点）
  docs/README.md               ← 改造为"上下文注入协议"：读什么、什么顺序、什么不读

L1  当前有效层（目标 ≤ 100 KB；其中"必读"≤ 25 KB）
  01-current/
    裁决记录.md                ← 只留条目表 + 轮次导读 + 未决摘要
    当前规划.md                ← 原"首版能力顺序"的全局节 + 在办/未办块
    待定清单.md                ← 全仓唯一未决住所（保持）
    adr/0001…0010              ← 去记录化后的契约
    guide/                     ← 用户手册（标记 userFacing：默认不进开发上下文）
  包规范（留在原位 packages/*/）  ← 实现口径与验证矩阵的唯一住所（决策 3）

L2  历史归档层（不注入）
  02-archive/
    register/裁决R*.md
    records/首版-记录-*.md（含两份"归档"）
    adr-appendix/附录/*.md
    baseline/{需求基线,评估报告,证伪实验计划}.md
  （evidence 保留原位，仅在索引里标 layer）
```

**目录迁移的取舍**：移动文件会让 400+ 处相对链接与按轮次存档的锚点全部需要改（`check-docs` 会红灯护卫，
但改动面极大）。因此**建议顺序**：先把 `layer` 字段与两条检查跑起来（P1），**再**决定是否真的移动目录；
若采用"原地保留 + 索引标 layer"，L1/L2 的区分由 `doc-index.json` 承担，目录名不必自解释。

## 四、关键手术细则

### 4.1 台账精简的边界
保留：条目表（五列）、轮次导读表、"未决/已闭"的一句话摘要与指针。
删除：§三里逐轮复述的叙事（P-40…P-49 的段落）——它的原文在按轮次存档里，本就"逐字迁移、不改写"。
**不要在精简时改动任何条目的结论列**（它是"逐字截取"的，动它就等于改口径）。

### 4.2 契约归位（决策 3）的判定规则
- **ADR 回答**：为什么这么定、边界在哪、代价是什么、明确不做什么；
- **包规范回答**：必须怎么写、有哪些常量与判据、验证矩阵与实测数字；
- **同一条事实只允许有一处权威陈述**，另一处只能是**带指针的一句话**。
- 落地检查：同一个数值（`c₃` 锚值、`HEADER_HEIGHT_PX`、`EXPORT_TICK_LENGTH_PX`、诊断码表、性能阈值
  `1 ms`/`2 ms`）在 L1 内**只允许出现一次字面量**，其余处只能写 `见 <文件>`。

### 4.3 常量分叉的收口（与 P1 检查配套）

### 4.6 spike 生命周期的通用规则（写进 `DOC-SPEC`）
从 G4-S 的既有先例提炼，供后续 spike 复用：

> **一个 spike 目录可以在满足以下全部条件后整体删除**：
> ① 其结论已**重新表达为进 `pnpm gate` 的 `packages/**` spec**，或测量协议已**移植进受维护的脚本**；
> ② 决策相关的数字已**冻结进 ADR / 计划文档**；
> ③ 全部引用已迁移或登记进白名单。
> **删除后，正文里的历史引用保留原路径并加括注**（先例："该目录已随 G4 落地删除，数字转入本包 spec"）。

## 五、迁移风险与纪律

1. **锚点风险**：任何文件重命名/拆分都会让**不带锚点**的引用静默落到文件顶部。`check-docs` 已强制
   "台账细则列必须带锚点"，但正文里的普通链接不受保护 ⇒ **拆分动作必须成对改引用**，在同一批里完成。
2. **记录层不可被当"当前值"引用**：迁移 G6–G8 正文时，回写的是**判定结论**，不是把记录层内容复制上来。
3. **不要在本阶段改任何契约语义**：发现语义问题时**登记**（进 [登记与本轮不做](05-登记与本轮不做.md)），
   由后续版本裁决。
4. **生成物同步**：`首版-文档索引.md` 与 `THIRD_PARTY_NOTICES.md` 用脚本刷新，不手写。
5. **本计划自身**：本目录是临时物，不追求与目标分层一致；收口方式见 [登记与本轮不做](05-登记与本轮不做.md) §收口。
