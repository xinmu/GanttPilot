（`group.querySelector('rect')` 取"第一个 rect"当条形 ⇒ 记录制假绿；`.axis-major-band` 拆 class
后选择器一起失效；连接点 `<rect>`→`<circle>` 后选择器限定标签 ⇒ 假阴性）。
裁决的实质因此是**仪器与判据的关系**，而不是"文件放在哪个目录"。

**2. ②的实质抓手（实测出的唯一缺口）：抓取点公式的三份实现 → 一处**

`(dayOfOrdinal(ordinal) − axisOriginDay) · pxPerDay + pxPerDay / 2`（"工作日**格的中点**"）此前有**三份**：

**3. 顺带的三处实测发现**

1. **`MEASURE_HOOK_VERSION` 是一条"没人核对"的承诺**：它的注释写着"供 CDP 侧核对（避免与旧产物混淆）"，

2. **两处仓内格式问题**（计划 §七 的"仓内格式"一行）：`dragScreenPoint` 里两条语句挤在同一行、
   `*/export async function runDragMeasurement` 注释收尾与声明挤在同一行——都是"无格式化器"的产物，

3. **`measure.ts` 的体量口径**：计划写 2,623 行，实测 **2,625 行**（非空 2,502）——现值为准。
