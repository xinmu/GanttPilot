**只判一个方向**：规范点名的符号 ⊆ 包入口（`packages/<pkg>/src/index.ts`）的导出面。
反向（哪些导出进"发布承诺"）**不在本检查**——`render-core` 有 302 个导出名，逐条要求文档化只会制造噪声；
那是 **P4-b 的公开面分类**。

### 2. 负向对照（新检查在现状上必须翻红）

在**未加 `allow`** 的现状上运行，恰好 **1 条 error**：

```
error [API] xlsx-protocol ← packages/xlsx-protocol/PROTOCOL.md ## 二、公共 API 点名了 `XlsxInput`（type），
      但 packages/xlsx-protocol/src/index.ts 不导出它（packages/xlsx-protocol/PROTOCOL.md:33）
```

这一条与 [06 §C2](06-批次记录-P3.md) 登记的观察**逐字一致**（"消费者能传值、叫不出类型名"）⇒ 判定面没有虚设。
其余 **88 个被点名的符号**（engine 77 / render-core 1 / xlsx-protocol 9 / pptx-renderer 1）全部命中入口导出面。

四条防静默失效的负向对照（selftest 逐条钉住）：段标题找不到 ⇒ 报"登记表已腐烂"；候选数掉到 `minCandidates`
以下 ⇒ 报"提取面塌了"；入口解析不出任何导出 ⇒ 报"解析器与写法已分叉"；`allow` 缺 `reason` ⇒ 报错。

**提取面是实测调出来的**（三次假阳都被钉进了用例）：① 行注释里的 `// max(ef)` 会把 `max` 当符号
（`SCHEDULE.md` §三）⇒ 先剥行注释；② 子节是"用法示例"，`PROTOCOL.md` §2.1 的 `applyCommand` 属 `engine`
⇒ 段范围截到下一个标题（子节不算）；③ 模块表列的是**文件名**（`manifest.ts`）⇒ 表格模式只认"首格由反引号
符号起头"的形态。

## P4-f 精简层结构复核（维护者插入批，先于 P4-b…e）

### 1. 触发与做法

触发：P4-a 收口时实测 **精简层 495.8/500 KB**（余量 4.2 KB），而 P4-b/c 还要往 L1 文档里加内容。
做法：不靠印象，先**量**，再按 [DOC-SPEC](../DOC-SPEC.md) §一 的五层模型与**反重复规则**逐个文档问三个问题——
① 有没有整份该进记录层的？② 有没有"过程/历史/教训"叙述仍留在 L1（反重复规则 3）？③ 有没有 L1 依赖**会随合流删除**的临时计划目录？

### 2. 精简层的实测构成（计入预算的 24 份）

| role | KB | 是什么 | 结论 |
|---|---|---|---|
| `contract` | 222.0 | ADR 0001–0010（形状与语义） | **本职**（五层模型的"契约"行）；D5 已做过一轮去记录化 |
| `spec` | 164.9 | 各包 `SPEC/SCHEMA/SCHEDULE/COMMAND/PERSISTENCE/PROTOCOL/PPTX.md` | **本职**（"契约"行）；其中"验证矩阵/判据表"由**反重复规则 2** 显式指定住这里 |
| `baseline` | 75.8 | `README` 29.7 / `DOC-SPEC` 22.0 / `CONTRIBUTING` 18.5 / `docs/README` 5.4 | **本职**（入口与文档规范）；`README` 已是**指针中枢**（"逐轮返工史与实测数字一律在记录层"） |
| `register` | 19.7 | 台账（`mustRead`） | **本职**；65 条条目行合计 13.7 KB、**中位数 216 B/条**、每条都带细则锚点 ⇒ 已是一行摘要 |
| `plan` | 13.2 | 当前规划 12.0（`mustRead`）+ 待定清单 1.2 | **本职**（判定层 12.0 KB 顶着 ≤12 KB 预算） |

**⇒ 三个问题的答案**：**① 没有整份文档该进记录层**（每一份都落在五层模型为它规定的那一层）；
**③ 只有一处**（`CONTRIBUTING` 指向 `04-refactor/05`，已修，见 §4）；**② 有，但是子句级的**：L1 里仍散着
"首版怎么错、以前写在几处、报文原文、试错经过"这类叙述——分布很碎（逐行扫的命中行上界 44.1 KB，
但绝大多数是**判据行里的版本标记**，如"（P-46 增补）"、"（依据）"，按反重复规则与跨层标记词要求**必须留**）。

**两处刻意不动的**（附实测理由，免得被当成漏做）：
- **包规范的验证矩阵**（`render-core/SPEC.md` §九 13.3 KB、`PPTX.md` §七 2.9 KB、`PERSISTENCE.md` §五 2.7 KB…）：
  这是**唯一 >20 KB 的杠杆**，但**反重复规则 2** 明写"包级矩阵在各包 `*/SPEC.md`/`SCHEDULE.md`"，
  且它是"spec 自足"的载体（读规范不必读测试）⇒ 属**决策 3 的范围**，本轮不动；要动需先改 DOC-SPEC。
- **台账条目表**（13.7 KB）：登记本体，"定过什么、现在还算不算"只能住这里（R52/P-54 把必读定义为"登记本体 + 当前规划 + 待定清单"）。
- 顺带量了**跨文档重复**：归一化后 ≥80 字符的重复行**只有 3 组 / 0.4 KB**（ADR 0006 ↔ `PROTOCOL.md` 的三行码表）
  ⇒ D6 的"双写收口"是有效的，L1 内部几乎没有可去重的复述。
