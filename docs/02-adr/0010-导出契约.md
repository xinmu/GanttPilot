## 背景

G7 要交的是**「所见 = 所导出」**：屏幕上的几何（`ViewModel`）必须能原样变成 SVG、PNG 与**原生可编辑**的 PPTX。
S1 已把 PPTX 的补丁路走通（`p:cxnSp` 双侧吸附、`p:grpSp` 坐标换算、WPS 真机拖动跟随），
但它**没有验证**三件事：① connector 的一端吸附在**组内子形状**上；② `a:custGeom` 折线这条降级路径；
③ 产物是否**逐字节可复现**（golden 比对的前提）。本轮以 S-G7 四条门禁把这三件事闭掉，再冻结形状。

## 决策

### 1. 三层落点：几何在 `render-core`，OOXML 在 `pptx-renderer`，DOM 只在 `apps/web`

| 层 | 落点 | 职责 |
|---|---|---|
| 导出投影 + 适配公式 + SVG 字符串 + 摘要 | `packages/render-core`（零 DOM，**进 `pnpm gate`**） | 全量渲染的 `ViewModel` → 结构化 SVG / 适配变换 / 图例与摘要数据 |
| PPTX 写出（模板 A） | `packages/pptx-renderer`（零 DOM，**进 `pnpm gate`**） | `ViewModel` + 摘要 → 原生形状 pptx 字节（`Uint8Array`） |
| PNG 光栅化、下载、导出面板 | `apps/web`（DOM 的唯一合法落点） | `svgString → Image → canvas → toBlob`；`Blob` + 下载；UI 与提示 |

**理由**：几何进 `apps/web` 就自动落在 `pnpm test` 的收集范围之外（[ADR 0007 §2](0007-渲染几何与裁剪契约.md)），
且 `pptx-renderer` 零 DOM 无法 import 应用内模块，只能复制第二份 ⇒ 两个真相源。

### 2. 导出投影 = **全量渲染**（不分窗口），且**不得用视口宽抬升 `contentWidth`**

`buildExportView({document, schedule, calendar, zoom})` 固定 `clipMode: 'none'`，
并以"文档右缘"（`contentWidthFor(..., viewportWidth: 0)`）作为内容宽——屏幕上那句
`contentWidth = max(视口宽, 右缘)` 是**滚动容器**的需要，导出没有视口这回事。

导出画布构成（**唯一公式**）：

```
innerWidth  = EXPORT_LABEL_WIDTH_PX + contentWidth      // 左列任务名 + 日期轴 + 绘制区
innerHeight = HEADER_HEIGHT_PX + rowCount · ROW_HEIGHT  // 顶部日期刻画带 + 全部可见行
```

`rowCount` 是**折叠过滤后**的可见行数 ⇒ **导出跟随折叠状态**（折叠隐藏的行与其边不画），
这与"折叠 = 用户对可见集的显式选择"一致，也与 `ViewModel` 的既有语义同源。

### 3. 适配：等比缩放到单页内并居中

```
scale   = min(availW / innerWidth, availH / innerHeight)     // avail = 页面 − 2·EXPORT_MARGIN_PX
offsetX = margin + (availW − innerWidth·scale) / 2
offsetY = margin + (availH − innerHeight·scale) / 2
```

**等比**是硬约束（非等比会把圆角矩形与菱形拉变形，S1 教训 2）。页面默认 **16:9**（720 × 405 pt），
写出后**读回 `p:sldSz` 断言等于声明值**（S1 教训 1：常量与容器漂移会让下游断言集体失灵）。
A4 与自定义页面属"可延后"。

### 4. SVG 语义化形态

`<svg xmlns width height viewBox>` + `<title>`/`<desc>`；分组序列
`g.axis`（色带 + 网格线）、`g.axis-labels`（日期刻度）、`g.rows`（每行 `g[data-task-id][data-kind]`
内含 `rect.bar`/`rect.bar-progress` 或 `polygon.milestone`）、`g.edges`（每条 `path` + `polygon` 箭头），
以及可选的 `g.legend` / `g.summary`（由导出面板开关控制）。

- **不含任何交互图元**：手柄、连接点、透明热区、拖动/建线/冲突/成环覆盖层一律不导出；
- 颜色与形状常量与屏幕**同源**（`render-core` 的同一批常量）；
- 坐标一律**整数 px**（`Math.round`），避免浮点噪声污染 golden；
- 文本用 `system-ui, -apple-system, 'Segoe UI', sans-serif`，字号固定（见 §11），**不随条缩放**；
- **左列标签的样式与文案**由 `exportLabels.ts` 单一真相处给出（汇总**加粗**、子行按 **WBS 深度缩进**、
  超宽截断加 `…`；**缩进不计入文本** ⇒ SVG 与 PPTX 的标签文本逐字相同，见 [附录细则 §1](附录/0010-增补.md)）；
- **图例里的依赖线画真箭头**（FS/FF 实心、SS/SF 空心），与画布同一形态（附录 §1）。

### 5. PPTX 形状映射（模板 A）

| 语义 | OOXML |
|---|---|
| 任务条 | `roundRect`（汇总条更矮、直角） |
| 进度 | 叠加 `rect`（同左缘、高度内缩） |
| 里程碑 | **菱形** `prstGeom prst="diamond"` |
| 依赖线 | `<p:cxnSp>` + `prstGeom prst="bentConnector3"` + `stCxn/endCxn` 双侧吸附 + **`a:tailEnd` 箭头** |
| 父子 | **一级 `<p:grpSp>`**（阶段汇总 + 其直接子任务；`off/ext` 与 `chOff/chExt` **均显式**、**等比**） |
| 日期刻度 | pptxgenjs 文本框（`axis-N`），放在表头带内 |
| 周末/节假日灰度与网格线 | 无描边 `rect`（`band-N` / `grid-N`），**注入在条形之前**（在底层） |
| 图例 | 文本 + **色块/箭头图元**（`legend-swatch-*`），与 `exportLegendItems()` 一一对应 |

**图面要素的完整清单与绘制顺序**见 [附录细则 §1](附录/0010-增补.md)（P-37 增补：刻度、背景与箭头
是**契约级**要素——正文初版只列了条/菱形/connector/group，人工复验因此发现它们全被漏掉）。

**锚点与站点表**（唯一登记处仍是 [P-8](../00-baseline/裁决记录.md) 第 1 条的出/入侧表）：

- 容器元素是 `p:nvCxnSpPr > p:cNvCxnSpPr`，其子元素是 `a:stCxn` / `a:endCxn`；
- `roundRect`/`rect` 的连接点序列：**0=上 1=左 2=下 3=右**（`idx_OOXML = COM − 1`，四站点已实测）；
- **不写 `<a:cxnSpLocks/>`**（WPS 原生产物也不写）；
- 形状 id：**从容器解析**（绝不硬编码 `id = idx + 2`），`IdAllocator` 保证全树唯一。

**S7-a 已证**：一端在组内子形状、另一端在顶层形状时，WPS 打开无修复、另存后锚点与形状 id 集合存活、
拖动顶层形状后 connector 几何重算 ⇒ **保留分组，不启用降级①**。

### 6. 降级序列（三条，按序启用）

1. **不分组**（全平铺 + `shapeName` 命名约定）——S7-a 已通过，**本项不启用**，仅作预案；
2. **`custGeom` 折线**（点列**直接取导出 SVG 的 path 端点**——T-4 的收益）——**S7-b 已证可用**；
   **折线同样带 `a:tailEnd` 箭头**（降级不许丢掉四类关系的形态，见 [附录细则 §1](附录/0010-增补.md)）；
3. 省略连线 + README 声明（最后手段）。

**永不退化为位图**：任何降级路径都必须仍是原生形状（可改色、可挪位）。

### 7. 内容口径（模板 A）

标题（项目名 + 档位，**不含导出时间戳**——保 golden 可复现）、图例（条/汇总/里程碑/四类箭头）、
自动摘要（任务数、依赖数、里程碑数、完成率、里程碑清单）。

- **完成率**用引擎同公式：叶子 `Σ(工期 × (progress ?? 0)) / Σ(工期)`（`null` 按 0；分母为 0 显示 `—`）；
- **里程碑清单**按日期升序，`outlineNumber + name + ISO`，上限见 §11，超出截断并注明"…共 N 个"；
- **文案只准一处生成**：图例取 `exportLegendItems()`、摘要取 `exportSummaryLines()`
  （两个渲染器都不得自己再写一遍——人工复验第 ④ 条即此处的教训，见 [附录细则 §1](附录/0010-增补.md)）；
- **SVG / PNG 是否附图例与摘要由导出面板的开关决定**（默认关）；**PPTX 模板 A 固定含**（EX-06）。

### 8. 单位与精度

`px → pt → EMU` 的仿射只在 `pptx-renderer` 的 `units.ts` 一处：1 pt = 12700 EMU，
1 inch = 72 pt = 96 px。写出的几何一律**整数 EMU**；页面与形状尺寸都由同一个 `scale` 推出。

### 9. golden 判定口径（**字节级**，S7-c 已定标）

产物 = 「pptxgenjs 容器 → JSZip 解包 → 注入形状 → **归一化** → 重打包」，归一化三步：

1. `docProps/core.xml` 的 `dcterms:created` / `dcterms:modified` 替换为常量；
2. **所有 zip 条目的 `date` 固定**为同一常量；
3. 重打包固定参数（`compression: 'DEFLATE'`、`platform: 'UNIX'`、条目顺序按名排序）。

S7-c 实测：未归一化时两次产物有 **20 个不稳定条目**（19 个 zip 时间戳 + `docProps/core.xml` 内容）；
归一化后**逐字节一致** ⇒ 出口条件⑤取**字节级 golden**，不需要退到"归一化指纹"。

> **一条必须一起读的诚实口径**：首轮实测把两次构建放在同一秒内，结果是"看起来确定"——
> 那是**巧合**：pptxgenjs 的时间戳是秒精度、zip 是 DOS 时间（2 秒精度）。归一化口径必须
> **跨过秒边界**验证（S7-c 显式延迟 2.2 s）。

### 10. 失败码与提示（闭集）

| 码 | 触发 | 用户可见提示 |
|---|---|---|
| `EXPORT_LIB_LOAD_FAILED` | 动态 `import()` pptxgenjs/pptx-renderer 失败（断网 CDN/构建缺失） | "导出库加载失败：本次可用 SVG/PNG" |
| `EXPORT_PNG_TOO_LARGE` | PNG 像素超过上限（§11） | "PNG 尺寸超限：请降低倍率或先折叠" |
| `EXPORT_NO_ROWS` | 全部行被折叠隐藏（`rowCount === 0`） | "没有可导出的行：请先展开至少一个阶段" |
| `EXPORT_UNSCHEDULABLE` | 文档不可排程（成环） | "当前文档不可排程：先修掉成环依赖" |

四码都走既有 `notice` 通道（P-30/P-31 的落点），**不新开第二套提示机制**。

## 备选方案与为何未采用

| 备选 | 未采用的原因 |
|---|---|
| 在 `apps/web` 里直接序列化屏幕上的 `<svg>` DOM | 只见**窗口内**元素（裁剪过）、且含交互图元；导出必须全量渲染（§2） |
| 用 `html2canvas` / 截图导出 PPTX | 违背"永不退化为位图"（EX-03）与"非截屏"（出口条件①）；且引入一个非必要的大依赖 |
| 不分组（从简） | S7-a 已证跨组吸附可用；分组是 EX-03 点名的"父子 group"语义，且是**已闭的**G1-c 判据载体 |
| 自定义 OOXML 包（不用 pptxgenjs） | 需要自写 theme/master/layout 全套部件，风险与工作量远大于收益；S1 已证"容器 + 打补丁"这条路 |
| golden 用"归一化指纹"（条目名 + sha256） | S7-c 已证字节级可达；指纹会漏掉"顺序/压缩参数变化"这类真回归 |

## 影响

- `render-core` 新增 4 个模块（导出投影 / 适配 / SVG / 摘要），**不改既有几何**：既有 spec 与 1,000 任务口径一字不动；
- `pptx-renderer` 从壳变成实现，新增两个运行时依赖（`pptxgenjs@4.0.1` = MIT、`jszip` = MIT OR GPL-3.0-or-later 取 MIT）
  与 `@ganttpilot/render-core`；需刷新 `THIRD_PARTY_NOTICES.md`；
- `apps/web`：导出面板 + PNG 光栅化；**pptxgenjs 一律动态 `import()`**，不得进首屏主 chunk（与 `exceljs` 同一纪律）；
- README 增导出章节与已知限制（PowerPoint 未验证、大文档单页不可读、导出不做格式保留）。

## 11. 数值回填（S-G7 定标；未回填前对应判据不得判"通过"）
