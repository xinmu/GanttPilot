### P-57 格式化器不引入

| 项 | 内容 |
|---|---|
| 裁决 | **不引入格式化器，也不加 `format:check`**；仓内格式由**人眼 + 评审**守，口径写进 [CONTRIBUTING](../../CONTRIBUTING.md) 的「代码格式」节 |
| 依据（实测） | 收口时清掉的仓内格式**粘连共 7 处**：`App.vue` 两条 `import` 挤在同一行、`measure/drag.ts` 两处 `};}`、`measure/index.ts` 一处参数与 `{` 挤在同一行（后三处随拆分清掉），`App.vue` 两条语句同一行 + 文件头 `* -` 粘连、`TaskTable.vue` 文件头一处。**7 处没有一处是工具报出来的**——全是人眼发现的 ⇒ 这类粘连是**缺陷**（不报错、只让人读错），不是风格偏好 |
| 为什么不做 | 引入即**新增依赖**（要走准入流程），且**必然**产出一次全仓重排的大 diff，与"一批一个提交、可独立 review"直接冲突 |
| 边界与翻案条件 | `CONTRIBUTING` 已写明**何时该翻这条**：人眼守不住的规模；届时必须**一并接受**三件事——固定版本 / `format:check` **只判不写** / `.prettierignore` 排除"逐字不改写"的层（记录层与按轮次存档） |

### P-61 生成物新鲜度守卫

| 项 | 内容 |
|---|---|
| 裁决 | 两份生成物（`docs/00-baseline/轮次导读.md`、`docs/01-roadmap/首版-文档索引.md`）与来源是否一致，**由门禁保证**，不再靠"记得跑一次 `pnpm docs:index`"。三件事同批落地：① 生成器的**输入来源从"索引"改成扫盘**（轮次导读的主题与细则文件扫 `docs/00-baseline/裁决R*.md`）；② 新增「**生成物与来源一致**」：就地重算一遍、与盘上文件**逐字节比对**；③ 断言 `doc-index.json` 里每个 `generated: true` 的文档**都在渲染器登记表里**（新加生成物却忘配渲染器 ⇒ 翻红） |
| 依据（实测的代价） | 收口期实测到一次**静默陈旧**：登记 `裁决R54.md` 之前先跑了生成器 ⇒ 提交里的轮次导读留着 `R54｜（该轮无独立标题…）｜—`，而 `裁决R54.md` 就在盘上、标题也在；`check-docs` 的存档覆盖检查**读的是索引**，所以当时**全绿** |
| 等价性与负向对照 | 等价性：轮次导读的扫盘版与索引版对当前仓库给出**同一张表**（3,263 字节逐字节相同）；文档索引当场抓到一行陈旧（盘上 `14.2 KB` vs 重算 `14.4 KB`），跑一次生成器后一致。负向对照：在索引里**新登记一份文档**而不重跑 ⇒ **恰好 1 条红**；把新检查块换成空数组 ⇒ **十类全绿** ⇒ 红确实是新检查报的，**旧门禁对这类陈旧完全无感** |
| 一条如实记下的边界 | 新检查的钉子**不是** `check-docs.mjs --selftest` 的合成用例（那族喂合成输入），而是**真树上的负向对照**——两个渲染器读的是活仓库；要合成钉子得先给它们注入 `root`，本轮**没做** |

### P-62 Python 版本口径

| 项 | 内容 |
|---|---|
| 裁决 | 加 `.python-version` **声明**版本（pyenv 多版本写法：`3.12` 然后 `3.14.5`），并在 `CONTRIBUTING` 写明口径。**是"声明"而不是"钉死"**——不声称两侧跑同一个解释器 |
| 依据（实测） | 差分测试的参照实现在 `tools/*-reference/`：本地实测 **3.14.5** 全绿、CI 跑 **3.12** ⇒ 两侧本来就在两个解释器上跑，写下来（并给 pyenv/asdf 用户一个自动切换的锚）比假装一致更有用 |
| 落地时实测到的代价 | **单行** `.python-version = 3.12` 在**没装 3.12** 的机器上让 `python` 直接不可用（pyenv shim 报 `No global/local python version has been set yet`）⇒ 差分测试与门禁**一起红**（"环境变了、不是代码变了"）。改双行后实测 `9 文件 / 94 例`全绿。`CONTRIBUTING` 已显式写下"**别再只写单行 3.12**" |
| 未实测的一半（如实登记） | "装了 3.12 的机器上会不会真的优先用 3.12"**没有实测**（本机只装了 3.14.5）；依据是 pyenv 多版本文件的既有语义（取列表里第一个可用的） |
