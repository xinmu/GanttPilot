### DOC-SPEC §4.5 的改法（两条件 + 两级动作）

1. **前置条件（保留原三条件）**：结论已重新表达为进 `pnpm gate` 的 `packages/**` spec、或测量协议已移植进受维护的脚本；
   决策相关的数字已冻结进 ADR / 计划文档；全部引用已迁移或登记进白名单。
2. **达到条件后的动作分两级**：
   - **可再生的探针代码 ⇒ 删除**（本条的"删除"只指这一级）；
   - **结论与证据 ⇒ 留档并登记为归档层**（`role: record` / `layer: archive`），不参与任何注入包。
3. **删除后**：正文里的历史引用**保留原路径并加括注**（先例："该目录已随 G4 落地删除，数字转入本包 spec"）；
   指向已删文件、且留在正文里的**链接**必须改成"原路径 + 括注"或登记进 `linkCheckAllowlist`（继承式，不给单条引用开口子）。
