### 1. 结论：三项**全部纳入 v0.1**，并作为**同一批次**落地

| # | 需求 | 裁定 | 一句话理由 |
|---|---|---|---|
| ① | 刻度行改为**两行**（上级刻度随档位变化） | **纳入** | 日档标签只有 `DD`（`buildAxis` 的 `iso.slice(8)`），"拼不出完整日期"直接损害 US-1 的"3 秒看懂图"；它是[附录 §2](../02-adr/附录/0007-增补.md) 口径下的**合法内容**（仍只承载时间刻度），故走"先登记、后实现" |
| ② | 指针所在**整行**用浅色背景指示 | **纳入** | 应用层**已有** `hoverTaskId`（每 `mousemove` 更新、带相等短路），只差一个视觉输出；它是"条体 ↔ 左表"的对齐参照，也是拖动/建线的位置参照 |
| ③ | **模板下载**（两页签 xlsx：填法与约束 + 小型示例） | **纳入** | 零新增依赖（`exceljs` 已在 lazy chunk、`exportXlsx` 已写规范 9 列），且与 G8 的"用户手册 + xlsx 协议规范"、`XL-09` 的"issue 样本上传引导"同源；代价是要补一块**协议面的登记**（§2.3） |

**"同一批次"是硬性口径，不是排期偏好**：三项分别改动**表头带高度 / 坐标基准 / 元素预算 / 导出 golden / 记录制快照**。
分成两批做，第一批刚通过的人工复验与四份记录制证据（`render-timing` / `chart-align` / `drag-timing` / `persist-drag`）
会在第二批**立刻作废**——[P-41 §9(a)](裁决R40.md) 与 [P-44 §9(a)](裁决R43.md) 已有两次"同轮刷新"的先例。

**若被迫削减的顺序**（先砍 ①，②③ 优先），三者**都低于主链路风险**：它们不碰排程语义、命令层（ADR 0003）与持久化契约（ADR 0009）。

### 2. 逐项的口径、落点与判据

#### 2.1 ① 两级刻度（`render-core` + `apps/web` + SVG/PPTX 两条导出路径）

**为什么不是"顺手加一行"**：三处连锁，缺一处就是"所见 ≠ 所导出"或门禁红。

| # | 连锁点 | 现状（改动前） | 本轮口径 |
|---|---|---|---|
| 1 | 轴模型只有**一级** | `AxisElement = band \| gridline \| label`（[`clip.ts`](../../packages/render-core/src/clip.ts) 的 `buildAxis`），标签取 `iso.slice(8/5/0,7)`（[`manifest.ts`](../../packages/render-core/src/manifest.ts) 的 `ZOOM_LABEL_FORMAT`） | 轴模型**扩一层**：下级刻度保持现语义；**上级分段带**由同一套语义派生（同一份 `Calendar`、同一档位、**同一处水平窗口裁剪**） |
| 2 | 表头带高度是**两栏共用**的单点常量 | `HEADER_HEIGHT_PX = 28`（`manifest.ts` 单点声明）；左表表头与图表表头带**外高必须相等**（`diagnoseRowAlignment` 的 `headerAligned`） | 常量**上调**（两行刻度所需的带高）；左表表头**同步**取得该高度（其第二行**留白**，见 §3）。`box-sizing: border-box` 与"外高"口径不变 |
| 3 | 导出是**第二条投影** | SVG 用同一份 `view.axis` 且标签固定 `y="18"`；PPTX 用 `slidePointOf(plan, x, HEADER_HEIGHT_PX + y)` 与 `innerH = HEADER_HEIGHT_PX + rows·ROW_HEIGHT` | 两行刻度**同时**进 SVG 与 PPTX（几何同源，不新造数字），PPTX 的适配公式随常量自动跟随；golden 字节同轮重取 |
| 4 | `c₃` 有**锚值** | `clipping.spec.ts` 钉 `116 / 70 / 89`（G4-S 实测锚） | 新增轴元素 ⇒ `c₃` **同轮重锚**；`scaleInvariance.spec.ts` 的"`c₃` 与文档总规模无关"必须继续成立（上级分段带同样走水平窗口裁剪） |

**登记义务**：本项按 [附录 §2](../02-adr/附录/0007-增补.md) 的既有要求**先在附录登记**（"带内可以放什么、放几行"），
再改代码；`axis-labels-not-in-header` 判据随之上移为新带高。

#### 2.2 ② 悬停行高亮（图层与预算）

| 决定 | 口径 | 为什么 |
|---|---|---|
| 落点 | **一个**覆盖层元素（`rect`），画在**窗口坐标**的轴组（与色带同族），**不画在内容滚动组** | 行高亮是"当前可视行"的概念；放进内容组会随内容滚动、并再叠一次 `−scrollTop`（§14.3/§15.2 的同源陷阱） |
| 不逐行加 `rect` | **不得**在 `drawnRows` 的每行模板里加 rect | 那会把它塞进逐行 diff 路径，并与"每帧固定开销"的 `c₄` 口径打架（ADR 0008 §11/§16.4） |
| 预算登记 | `countOverlays` **新增一个 overlay 项**（每帧固定开销），逐项枚举的第二路计数同步 | 预算常数 `c₁`/`c₂`/`c₃` **一字不改**；`c₄` 的固定部分 +1 |
| 左表 | 用**纯 CSS** `.row:hover`（零 SVG 元素、零预算） | 判定入口与预算都在图表侧；左表不进任何判据 |
| 颜色与层级 | 浅色、**与周末/假日色带区分**（色带 `F4F6F8`），**画在条体之下** | 否则周末与悬停混为一色、或高亮压住条体（与 P-37 的"背景层先注入"同口径） |

#### 2.3 ③ 模板下载（协议层生成 + 应用层下载）

| 决定 | 口径 |
|---|---|
| **生成落在 `xlsx-protocol`**（纯函数，零 DOM），**不在应用层手搓 workbook** | 列契约（`COLUMN_SPECS`）与容差只有一份真相源；应用层只做"按钮 → 动态 `import('exceljs')` → 生成字节 → 下载"，与既有导入/导出路径同一姿势 |
| 页签结构**冻结** | ① **任务**（规范 9 列、列序与表头与 `COLUMN_SPECS` 一致，可直接被导入）；② **填写说明与约束**（列语义、4 类依赖语法、容差闭集要点、常见错误与诊断码对应）；③ **最小示例**（`demoPlan.ts` 的 15 行演示计划、含 4 类关系与里程碑）。**页签名在实现轮定稿并回填本表**（结构规则冻结、字面名可微调——沿用 [P-42](裁决R41.md) 的"结构冻结、字面可打磨"手法） |
| 契约登记 | 这是 xlsx **导出物的新形态** ⇒ 新增 [ADR 0006 附录 §1](../02-adr/附录/0006-增补.md#1-模板文件多页签形态的登记p-46-增补新增adr-0006-2-的单工作表口径不变) 并在 [PROTOCOL.md](../../packages/xlsx-protocol/PROTOCOL.md) 增一节；ADR 0006 §2 的"单工作表"约束的是**规范表**的读入口径，**不是**模板文件不得有别的页签（PROTOCOL.md §3.1 的"表头打分 + 缺省优先表名 `任务`"已给出读入口径） |
| 判据（进门禁） | 页签集合与名称、9 列列序与表头、**两次生成逐字节一致**（沿用固定时间戳手法） |
| 判据（`smoke:build`，打包产物） | 点「模板下载」→ 文件真的落盘 → **把它再导入回来**（文档 `error 0`）⇒ "模板与协议随时对齐"成为可判定的 |
| 版本化产物 | 模板是**版本化产物**：模板与协议任何一侧改动，上两条判据都会红 ⇒ 不存在"模板悄悄过期" |

### 3. 本轮当场定下的三个开放点（不写进待定清单）

| # | 问题 | 定值 | 理由 |
|---|---|---|---|
| 1 | 上级刻度的**标签与省略规则** | **日/周档上级 = `YYYY-MM`、月档上级 = `YYYY`**；上级刻度按**分段带**表达：**段内只在左端写一次文本**、段的左右边界画竖线、文本随段起点被水平裁剪 | 既补足日期信息，又不出现满屏重复文本（`buildAxis` 的元素之一是"合成极大连续段"，分段带与它同族） |
| 2 | 左表表头**第二行**的内容 | **留白**（只保高度与分隔线），不新增文字 | 表头带的内容集合仍是**时间刻度**（[附录 §2](../02-adr/附录/0007-增补.md)）；放"档位提示"一类的文字必须先改附录，本轮不做 |
| 3 | 悬停高亮的**范围** | **图表侧**：浅色行带（计入预算的 1 个覆盖层元素）；**左表侧**：纯 CSS `:hover`（不入预算） | 判据与预算只在图表侧，两侧**不共享**判据 |

### 5. 明确不做（本轮）

- **季刻度**（仍是 [ADR 0007 §10](../02-adr/0007-渲染几何与裁剪契约.md) 的明确不做项）——两行刻度**不等于**新增档位；
- **上级刻度的交互**（点击上级带切档、折叠上级带）：归 v0.5 的键盘/交互流（P1-07/08 口径）；
- **表头带内放"档位/单位提示"或任何非刻度文本**：须先改 [附录 §2](../02-adr/附录/0007-增补.md)（本轮不做）；
- **悬停高亮进驻左表之外的任何判据**、以及**多行同时高亮**（多选/批量归 v0.5）；
- **模板的静态文件分发**（仓库内不放 `.xlsx` 二进制）：模板由协议层**运行时生成**，避免"二进制与协议分叉"；
- **模板的页签超过三个**、模板内嵌日历例外说明等扩展（v0.5 视反馈再定）。
