### P-27 文档分层：登记 / 契约 / 判定 / 记录 / 证据各只有一处

**1. 事实（本轮实测）**：`裁决记录.md` 207.4 KB / 1878 行 / 25 个轮次，`首版能力顺序.md` 108.3 KB，
两者内部同时承载四种性质的内容——结论、论证与实测、逐轮返工史、遗留待定项；
G5 一节 31.7 KB 中「规划 + 出口条件」只有约 45 行，其余全是落地记录与四段返工史；
同一张验证矩阵在 [render-core/SPEC.md](../../packages/render-core/SPEC.md) §九、
[ADR 0007](../02-adr/0007-渲染几何与裁剪契约.md)、[ADR 0008](../02-adr/0008-列身份所有权与拖拽交互契约.md) §11
与路线图之间被复制了四遍。

**2. 裁决**：文档分五层，**同类信息只允许有一处权威陈述**，其他地方只能写指针——
登记（本台账 + 按轮次存档）、契约（ADR 与各包规范）、判定（路线图的能力边界与出口条件）、
记录（落地记录 / 增补 / evidence / spikes）、待定（[首版-待定清单](../01-roadmap/首版-待定清单.md)，全仓唯一）。
细节与模板见 [DOC-SPEC.md](../DOC-SPEC.md)。

**3. 与 P-3 的关系（本条的例外，必须显式登记）**：P-3 写「文档不做版本号另存」
「裁决类信息统一进 `裁决记录.md`」。本条**新增**按轮次区间命名的存档文件
（`裁决R<起轮>-R<止轮>.md`），**不是把同一份文档另存成多版**：台账仍是唯一登记处，
承担「定过什么、现在还算不算」；存档只是细则，承担「当时为什么这么定」，
且**一轮只入一份、只追加、不重写**。除该例外外 P-3 继续有效。

**4. 硬约束**：任何文件触及体量上限时，**动作是拆分或迁移，不是提高上限**；
提高上限必须在本台账追加一条新裁决。上限登记在 [doc-index.json](../doc-index.json)，
由 `pnpm docs:check` 判定。

**5. 与既有裁决的关系**：**不取代、不修改**任何 `Dn/Rn/Tn/Pn` 条目；
历史文字的**位置**变了、**内容一字未改**（逐字迁移，"不改写"约束按内容而非位置解释，本条即该解释的登记）；
**不放宽**任何 DoD（`c₁`–`c₄`、`Schedule`/文档 schema/诊断码表、性能判据全部不变）。

**6. 代价（明确接受）**：
- 链接必须跟着搬家：27 行 / 44 处同文件链接改为「所属存档 + 条目锚点」，
  其余约 295 处指向 `裁决记录.md` 的链接继续有效（文件名与路径不变）但语义降为「台账」；
- 台账的「状态」列需要人工判断（`有效/已闭/取代/未决` 四值闭集），
  它会在每次裁决后变陈旧——因此**只有 `未决` 与 `已闭` 承担「当前该看哪一行」**，
  且 `未决` 与待定清单由 `pnpm docs:check` 双向断言；
- markdown 从此进入门禁（新增 `pnpm docs:check` 一步）：任一链接/锚点失效即阻断推送，
  这是"文档结构可判定"的入场费。

**第二十七轮遗留待定**
无新增。P-21–P-25 的遗留项统一收敛到 [首版-待定清单](../01-roadmap/首版-待定清单.md)。
