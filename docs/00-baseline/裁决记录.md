# 裁决记录（Decision Log）——台账

> **本文件是裁决的唯一权威登记处**（规范见 [DOC-SPEC](../DOC-SPEC.md)）。**登记在这里，论证在存档。**
> 本文件回答「**定过什么、现在还算不算**」；逐轮细则（当时为什么这么定、实测与教训）
> 在 `裁决R<起轮>-R<止轮>.md`，**逐字迁移、不改写**，修订历史由 git 保存。
> 条目一经裁决不改写（如需推翻，追加新条目并注明"取代 Rn/Tn"）。
> 约定：`D-n` = 第一轮裁决；`R-n` = 第二轮裁决；`T-n` = 第二轮技术权衡；`P-n` = 第三轮起的裁决；
> `G-n` = 待定缺口（见《评估报告》§3.2，**与能力块编号 `Gn` 不是一回事**）。
>
> **本轮（第二十七轮 P-27）的治理口径**：文档分五层、同类信息只有一处权威陈述。
> 本台账是**登记层**；**未决项只有一份清单**——[首版-待定清单](../01-roadmap/首版-待定清单.md)；
> 能力边界与出口条件见 [首版能力顺序](../01-roadmap/首版能力顺序.md)；契约见 [docs/02-adr](../02-adr/)。
> 体量上限与检查项见 [doc-index.json](../doc-index.json) 与 `pnpm docs:check`。
