### P-35 G7 的开工前置：导出契约冻结、四项口径选择与 S-G7 准入判定

**本轮一并定下的四项口径**（口径本身来自维护者的直接选择，本文件只登记结论与代价）：

1. **范围＝G7 全块**（SVG + PNG + PPTX 模板 A + WPS 证据链与出口条件逐条判定）；
   不按"先交 SVG/PNG、PPTX 另发布"的延后分支走——该分支仍由路线图 §四 保留为**受阻时的降级**；
2. **大文档单页口径＝全量渲染 + 等比缩到单页 + 导出前可读性提示（不阻断）**：
   导出是**全量渲染**（ADR 0007 §10 的既定口径），因此 1,000 行会被压到不可读；
   正确动作是"提示用户折叠/换档/只导汇总"，而不是悄悄改口径（不分页、不按窗口导出）；
3. **导出物内容＝给用户开关**：SVG/PNG 的「含图例与摘要」由导出面板决定（默认关）；
   **PPTX 模板 A 固定含**（EX-06），界面对该格式置灰并说明原因（不静默忽略）；
4. **S1 spike 目录保留**：它是 G1-a~G1-d 的已闭证据（被 README、证伪实验计划、两份按轮次存档等
   12+ 处引用）。S1 结论 §九 的"产品化时删除 spike"建议以"证据已迁移"为前提，本轮**不迁移 S1**，
   因此不删——**G7 的算法在 `pptx-renderer` 重新实现**，spike 只作形态基准与历史证据。

**S-G7 四条准入门禁（记录制 + WPS；探针 `spikes/g7-export-probe/`，落地后删除并迁移证据）**：

| 门禁 | 判据 | 实测结论 | 证据 |
|---|---|---|---|
| **S7-a** 跨组吸附（S1 未覆盖） | 一端吸附在**组内子形状**、另一端在顶层形状：WPS 打开无修复、另存后锚点与形状 id 存活、拖动后 connector 几何重算 | **通过**：`stCxn id=5 idx=3 / endCxn id=2 idx=2` 存活；形状集合前后一致；拖动 `bar-top`（60,60 → 300,120）后 `dep-cross-1` 的 `xfrm` 由 `2032000,1219200,1270000,939800` 变为 `3302000,1981200,1778000,177800` | [报告](../../packages/pptx-renderer/evidence/g7-s7-a-b-wps.md) + `evidence/wps/A-cross-group-*.xml` + `evidence/vision/A-cross-group-*.png` |
| **S7-b** `custGeom` 折线（降级②） | 折线形状被 WPS 接受：打开/另存无修复弹窗、`custGeom` 存活 | **通过**：无修复、另存后 `<a:custGeom>` 存活、形状名集合一致 | 同上（`B-custgeom*`） |
| **S7-c** 字节确定性（golden 前提） | 同一输入两次导出是否可逐字节比对；不可时归一化能否消除 | **通过（归一化后逐字节相等）**：未归一化时 **20 个不稳定条目**（19 个 zip 时间戳 + `docProps/core.xml` 内容）；**固定 core.xml 时间字段 + 固定全部条目日期 + 固定压缩/顺序**后**逐字节一致** ⇒ ADR 0010 §9 取**字节级 golden** | [`g7-s7-c-determinism.md`](../../packages/pptx-renderer/evidence/g7-s7-c-determinism.md) |
| **S7-d** 单页适配数值 | 16:9 单页下的缩放比/行高/字号，用于回填常数与提示阈值 | **通过**：演示计划日档 scale **0.59** / 行标签 **4.9 pt**（不可读）、周与月档 **1.31 / 10.8 pt**（可读）；1,000 行三档均 **0.02 / 0.2 pt**（不可读）⇒ 阈值取"有效字号 < 6 pt 即提示"，动作按"有没有可读档位"分两支 | [`g7-s7-d-fit.md`](../../packages/pptx-renderer/evidence/g7-s7-d-fit.md) |

**一条必须与 S7-c 一起读的诚实口径**：首轮实测把两次构建放在**同一秒**内，结果是"看起来确定"——
那是巧合（pptxgenjs 的时间戳是秒精度、zip 是 DOS 时间即 2 秒精度）。确定性判据与证据必须**跨过秒边界**
（S7-c 显式延迟 2.2 s）；这条纪律已写进 ADR 0010 §9 与 `PPTX.md` §四。

**由此确定的降级序列**（ADR 0010 §6）：① 不分组——**不启用**（S7-a 通过）；② `custGeom` 折线——**可用**（S7-b 通过，且端点直接取自导出 SVG 的 path，视觉差异最小）；③ 省略连线 + README 声明——最后手段。**三条都不退化为位图。**

**开工前置的闭合判定**：ADR 0010 已落库（形状与语义冻结、数值由 S7-d 回填），S-G7 四门禁全部通过
⇒ **G7 具备写产品代码的条件**。落地口径与出口条件判定见 [R35](裁决R35.md)。
