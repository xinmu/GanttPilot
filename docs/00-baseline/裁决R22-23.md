### P-22 批次 A 已落地；R7 是 P-21 未预见的第七个根因；第 13 条已闭

**2. R7：P-21 对第 1、2、7、8 项的 R1 归因**不完整**（本条**补正**，P-21 原文不改写）**

证据链（三条都可复核）：

| 证据 | 事实 |
|---|---|
| 死字段 | `GestureState.dragging.pointerStartX` 存了却**从未被读取**（全仓只有赋值处）——初稿的设计意图就是"抓取点相对" |
| 绝对语义 | 候选曾是 `ordinalAtX(pointer.x)`：按下位置在条体中部时，条体左端**立刻跳到抓取点那一天的序号**（与 R1 无关，修好坐标仍然发生） |
| 公式错位 | `resize-duration` 的 patch 写作 `候选 − 原开始 + 工期`：在右端**按下不移动**即松手 ⇒ 工期 ≈ `2D − 1`（复核第 2 项"工期翻倍"的第二个成因），拖动期锚点写在新开始 ⇒ **松手回原位但日期仍变**（复核第 7 项的字面成因） |

**落地**：候选改为**抓取点相对**并按模式分别定义（`move`/`resize-start` = 新开始；`resize-duration` = 新完成）、
**零位移不产出命令**、**零时长的完成日 = 开始日**、夹取按模式分工、覆盖层改画 `dragPreviewFor` 的**结果轮廓**
（`resize-duration` 拖动期条体本体不动，会话锚点形状**不扩**）。契约文字见 ADR 0008 §13。

**3. 落地期又抓出两处真实缺陷（都由本轮的**新证据**当场抓出，P-21 未预见）**

| # | 现象 | 根因 | 抓出它的判据 |
|---|---|---|---|
| ① | **拖动累积加速**：拖 3 个工作日实际落到 **21 个工作日**之后 | `reduceGesture` 的候选基准取成了**指针当前所在行**的 `es`——而视图带着会话锚点重算，`es` 已经跟着候选走了 | 记录制 `--drag` 新增的**位移断言**（松手后 `startDate` 必须 = 按下的开始序号 + 天数）；随后落为 `gesture.spec.ts` 的"带会话锚点重算也不会累积"一例 |
| ② | **导入的成环边从未进过问题清单**（G5 出口条件⑤在应用层不成立） | `onImportFile` 只把**条数**写进提示，`importXlsx` 的协议层诊断**没有保留**——而文档层与排程层是每帧重算的 | 记录制 `--import`：诊断面板里读不到 `XLSX_CYCLE_EDGE_DROPPED`（任务/依赖计数却是对的） |

两处都**不新造语义**：① 是"抓取点相对"这条口径在执行层的必然要求（基准必须在按下那一刻捕获）；
② 是三层拼接**本来就写在面板注释里**的口径（ADR 0006 §7），只是协议层从未接上。

**4. 判据（全部进 `pnpm gate`；`gesture.spec.ts` 13 → 24 例，仓库 **47 spec / 602 例**，门禁全绿）**

十一组新判据：① 屏幕坐标 → 内容坐标**与事件目标无关**（同一 client 点、两个目标 ⇒ 同一结果）；
② 条体包围盒 ± `HIT_TOLERANCE_PX` 之外按下 ⇒ `idle`；③ 里程碑按**菱形包围盒**命中；
④ 三语义"按下不动即松手" ⇒ **不产出任何命令**；⑤ `move`：**中部抓取不跳位**、位移多少就是多少；
⑥ `resize-start`：向右拖 n 天 ⇒ 开始右移、**完成日不动**（patch 不含 `endDate`）；
⑦ `resize-duration`：按下不产出命令（**工期不翻倍**）、向右 n 天 ⇒ 工期 +n、开始不动；
⑧ 里程碑：`move` 的完成日 = 开始日，右半区拖动把它变成有长度的任务；
⑨ **预览与提交同源**（预览区间 == 落库 + `compute` + `taskBounds` 之后的区间）；
⑩ 带**会话锚点**重算时不累积（第 3 条①的判据）；
⑪ **拖出日历地平线不抛错**：完成日退化为 `null`（与 `editToCommand` 的工期分支同口径）、预览返回 `null`
（两个几何函数在越界时会抛错，而预览函数在**渲染期**被调用——因此必须收口为"不可表示"）。

**负向对照（临时改回旧写法，对应判据必须变红——本轮回合执行过一次，结果如下）**

| 临时变造 | 变红的判据 |
|---|---|
| `pointerFromClient` 去掉滚动项 | ① |
| `barHitFor` 恒真 | ② ③（3 例） |
| 候选换回绝对语义（`grabOrdinal` 置 0） | ⑤ `snap`/`allow` 四象限 ⑦（3 例） |
| 去掉"零位移不产出命令" + 旧 `resize-duration` 公式 + 旧完成日公式 | ④ ⑦ ⑧ ⑨（4 例） |
| 候选基准取"指针所在行的 `es`" | ⑩（1 例） |
| 完成日换回直接 `calendar.isoOfOrdinal` | ⑪（1 例） |

### P-23 批次 D 已落地；R6 的两个候选机制都被证实；R8/R9/R10 是 P-21 未预见的根因
