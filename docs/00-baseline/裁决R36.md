### P-37 G7 人工复验：主流程通过；四项功能缺口与一项样式按报文返工

**报文（逐字要点）**：① A、B 区全部通过，C 区未做人工验证，结论"主流程验证通过"；
② B 区按列表通过，但 PPTX 存在四个问题：1）没有日期刻度；2）条体显示区没有背景刻度线与节假日/周末灰度；
3）连接线只有线没有箭头；4）图例摘要和 SVG/PNG 内容不一致；③ 样式问题：父节点没有加粗、子节点没有缩进，
视觉区分度不够。

**逐条根因与修法**：

| # | 报文 | 根因（**不是"手滑"**） | 修法 | 判据（进 `pnpm gate`） |
|---|---|---|---|---|
| 1 | PPTX 没有日期刻度 | 正文 §5 的**形状映射表只列了条/菱形/connector/group**，刻度与背景不在契约清单里 ⇒ 实现自然只画那四类 | 把"图面要素"升为契约级清单（[附录 §1](../02-adr/附录/0010-增补.md)）；刻度文本取自 `view.axis` 的 `label`（与 SVG 同源），命名 `axis-N` | 刻度文本框数 == `view.axis` 的 label 数，且**文案逐条相同** |
| 2 | 没有背景刻度线与周末灰度 | 同上（契约清单缺"背景层"） | 无描边 `rect` 画 `band-N`（`F4F6F8`）与 `grid-N`（`E4E7EC`），取自同一份 `view.axis`；**注入在条形之前**（底层） | 计数与 `view.axis` 一致；**绘制顺序 asser t：`band` < `bar` < `cxnSp`** |
| 3 | 连接线只有线没有箭头 | `<a:ln>` 只写了 `solidFill`，**没写 `a:tailEnd`** ⇒ 渲染器不画箭头 | 每条线显式写 `<a:tailEnd>`：`FS/FF` = `triangle`（实心）、`SS/SF` = `arrow`（空心），与 SVG 的 `ARROW_FILL` 同口径；**降级②的 `custGeom` 同样带箭头** | `triangle` 次数 == FS/FF 条数、`arrow` 次数 == SS/SF 条数（演示计划：10 / 4） |
| 4 | 图例摘要与 SVG/PNG 不一致 | **两处各写了一遍文案**（PPTX 手写"任务：蓝条…"，SVG 用 `exportLegendItems()`），且 PPTX 图例没有色块/箭头图元 | 文案收进 `render-core`：图例 `exportLegendItems()`、摘要 `exportSummaryLines()`（新增）；**图例补图元**（`legend-swatch-*`，坐标与文本共用 `planTemplateA().legendRows`） | 图例 7 条 + 摘要行**逐字**取自共享函数；旧文案（`任务：蓝条`）**不得出现**；7 类图元 + 4 个箭头全在 |
| 5 | 父节点没加粗、子节点没缩进 | 导出的左列只有**一列**文本，而层级信息此前只靠 `outlineNumber`；样式没有任何口径 | 新增 `render-core/exportLabels.ts`（**单一真相处**）：加粗 = 汇总行、缩进 = WBS 深度（12 px/级、封顶 3 级）、截断规则；SVG 与 PPTX 共用它 | 加粗/缩进逐值断言；**两边的标签文本逐字相同**（缩进不进文本） |

**一条元教训（比这五条修法更重要）**：这四项功能缺口的共同根因是"**契约清单不完整**"——
ADR 0010 初版把"形状映射"写成了契约，却没写"**图面要素清单**"（刻度 / 背景 / 箭头 / 图例图元 / 标签样式）。
于是实现严格地只做了被点名的四类，而人工复验一眼就看出"这不是一张甘特图"。
⇒ 契约要冻结的不是"用什么形状"，而是"**一张图上有哪些东西**"；
[附录 §1](../02-adr/附录/0010-增补.md) 因此按"图面要素 + 绘制顺序"重写。
