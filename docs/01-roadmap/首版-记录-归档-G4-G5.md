**内容**
- **纯 SVG**（弃 Canvas+SVG 混合）：刻度、条形、进度、里程碑菱形、汇总条、依赖连线（正交路由 + 类型箭头）全部为 SVG；
- **几何与裁剪内核落 `packages/render-core`（零 DOM / 零框架，纳入铁律约束集）**：
  出**视图模型**（矩形、折线点列、文本锚点、样式键——只出数字与枚举，不出 SVG 字符串、不出 DOM），
  `apps/web` 与 G7 的导出投影**共用同一份几何**（铁律 #2 / EX-09 的载体，依据见 [ADR 0007](../02-adr/0007-渲染几何与裁剪契约.md) §2）；
- **时间轴与 x 坐标**（[ADR 0007 §3](../02-adr/0007-渲染几何与裁剪契约.md)）：x 轴按**自然日连续**排列，
  非工作日照常占位并视觉区分（与 D-4 的 MS Project 惯例同源）；条形**右边界 = `dayOfOrdinal(ef − 1) + 1`**
  （`ef` 是排他序号，直接用 `dayOfOrdinal(ef)` 会让跨周末的条多出一段空隙）；
  汇总条取 `summaryEs`/`summaryEf`，**`es[i] === -1` 是唯一的汇总判别式**（SCHEDULE.md §三）；
  序号↔日期翻译**必须用同一个 `createScheduleCalendar(document)`**，`-1` 哨兵绝不可喂给 `dayOfOrdinal`；
  **拖拽吸附的分工**：G4 提供 `ordinalAtX`（吸附候选），**吸附时机由 G5 决定**；
- 左表右图分屏 + 行内编辑（VW-02）：**左表列集合锚 G3 的 9 列契约**（不新造第四套列语义）；
  行内编辑**只走 `task.update`**（含 `collapsed`），编辑后按"**受影响行 + 受影响边**"重绘
  （`affectedClosure()` + 沿 `parentId` 补祖先链，SCHEDULE.md §八 已声明该边界），**不整表重建**；
- **折叠渲染**（DM-01 的渲染行为归本块，G1.2 只承载 `collapsed` 字段）：
  可见行 = 树序经折叠过滤；**折叠隐藏的行不渲染其边**（否则悬空线）；固定行高假设不因折叠/展开改变；
- 刻度缩放：日/周/月（VW-04；**季刻度延后**）；
- **虚拟滚动（VW-05）+ 裁剪（硬性架构要求）**（[ADR 0007 §6](../02-adr/0007-渲染几何与裁剪契约.md)）：
  - **行窗口裁剪**：可见行 + 上下各 `ROW_BUFFER` 缓冲行；
  - **边窗口裁剪：必须用「边所跨行区间 ∩ 可见行窗口」求交**——仅按"两端点是否可见"裁剪会错误隐藏跨屏长箭头；
  - **文档里的全部 `links` 都画**（含被传播忽略的汇总端点边，用**样式区分**、**不新开诊断码**）——
    渲染呈现的是文档数据，与 SCHEDULE.md §四.6 的"有效图 vs 结构图"不冲突；
  - **裁剪先于几何计算**；拖拽期不做逐帧 DOM 重建；
  - **元素预算**：`#elements ≤ c₁·visibleRows + c₂·visibleEdges + c₃`（常数由 G4-S 回填）；
- **依赖线路由**：出/入边策略的**唯一登记处是 [P-8](../00-baseline/裁决记录.md) 第 1 条**
  （FS 右出→左入、SS 左出→左入、FF 右出→右入、SF 左出→右入；左右连接点 = 该边中点）；
  本块冻结**折点参数**（`EDGE_STUB_PX = 8` / `EDGE_WRAP_PX = 12` / 4 类箭头形态 = 填充 × 朝向，
  见 ADR 0007 §5 与 §11 第 3 项）；**左侧 gutter 是 SS/SF"左出回绕"走线的前提**；
  **同侧多线避让 v0.1 不做**（出现真实取舍则另立 ADR，P-8 遗留 3）；
- 工程细节：`shape-rendering="crispEdges"` 避免 1px 模糊；缩放用 `vector-effect="non-scaling-stroke"`；
  交互热区用独立透明 `<path>`（不得给可见图元加大热区）；
- **Vue 落地约束（T-1）**：任务集合用 `shallowRef`/`markRaw` 承载，**只对可见窗口 + 受影响子图做响应式**；固定行高（虚拟化前提）；
