## 二、明确未做（诚实声明，不是遗留缺陷）

1. **远端 CI 的真实验证**：`ci.yml` 在 P5-b 补了两步（`bundle:offline` / `docs:check`，CI 六步 → **七步**），
   改动**已在本地验完**（两步各自 `exit 0`，`check-gate-steps` 判定通过），但**远端从未真实跑过**——
   合流当时本机 `origin`（`github.com/xinmu/GanttPilot.git`）**访问不通**。⇒ **合流后第一件事：push 一次看 CI 绿**。
2. **N1 多标签写保护（IndexedDB 路径）**：本轮只把文档与注释改成**限定措辞**（`PERSISTENCE.md` 的不变量④
   只在降级路径成立）。按决策 4 归 **v0.5**。
3. **N2 PPTX 与 SVG 的进度条内缩统一**：`PPTX.md` **如实描述**当前行为（EMU 上 `y+1`/`cy-2` ≈ 无可见内缩），
   并标注与 SVG 不一致。归 **v0.5**。
4. **N16 建线预览的箭头朝向**（8 组形状里 **4 组**与落地后相反）：**不改**——它改的是**可见朝向**，
   需要一次人工复验或记录制快照才能证"改对了"。
5. **N18 `SnapshotStore.saveCheckpoint` 要求调用方给 `id`**：**不改**——动的是契约面（ADR 0009）**且**改浏览器写入行为，
   而"`autoIncrement` + 显式 `id: 0` 到底用 0 还是回退自增"**没有实测**。
6. **N19 `scripts/**/*.mjs` 的类型覆盖**（实测 **489** 处）：**不做**——大部分是标注量，与"一批一提交"冲突。
7. **N20 证据层非 `.md` 资产的引用面**（40 份里 **15 份**无人提及）：**不做**——先要设计"目录级所有权"的形态。
8. **在线 Demo / HTTP 托管**：与 v0.1 相同（仓库不把托管变成对外承诺）。

## 三、接手要点（每条都写清"落在哪、为什么现在不做"）

### 3.1 N1 多标签写保护（v0.5）
- 判据：`existing.writerId !== record.writerId && existing.updatedAtMs > record.updatedAtMs`（与内存适配器同口径）；
- 需要一次 **读改写**（`get` 再 `put`），注意 IndexedDB 事务边界（现有 `withStore` 每操作开一个事务）；
- 需要一条**浏览器侧判据**（`smoke:build` 或记录制探针）——这条路径**目前没有任何自动化覆盖**；
- 实现后把 `PERSISTENCE.md` 的限定措辞改回"两条路径都成立"。

### 3.2 N2 PPTX 进度条内缩（v0.5）
- 把 px 换算成 EMU（`ptToEmu` / `EMU_PER_PX` 一族已在 `units.ts`）；
- 换算后**必然改变 PPTX golden 字节数** ⇒ 按 golden 重锚的纪律：同批更新 `PPTX.md` 的字节数/`sha256`
  与 `packages/pptx-renderer/src/template.spec.ts` 的钉子（P4-c 起它已被钉住）。

### 3.3 N16 预览箭头朝向
- **修法二步**：① 谓词**先下沉**进 `render-core` 的 `route.ts`（`routeSides(type).enter` 是唯一来源，
  预览改由它决定朝向）；② 补一条"8 组逐组一致"的留档用例 + 负向对照。
- **为什么不能顺手改**：它改的是**可见朝向**，而 `apps/web` 没有判据入口（P-40：不引 jsdom/Playwright）
  ⇒ 判据必须落在 `render-core`。

### 3.4 N18 `saveCheckpoint` 的 id 归属
- 修法：入参收窄成 `Omit<StoredSnapshot, 'id'>`，并去掉 `usePersistence.ts` 里那个**占位 `id: 0`**；
- **先实测**：真 Chrome + 页面内建 `{ keyPath: 'id', autoIncrement: true }` 的 store，
  复刻"显式 `id: 0`"与"省略 `id`"两种写法，读回键集合来判定；
- **两个避坑点**（v0.2 的探针踩过）：`file://` 页面要带 `--allow-file-access-from-files`；
  `Runtime.evaluate` **必须自带超时**，否则挂住的是整批；
- 建议落点：并进 `scripts/offline-artifact-probe.mjs` 的①节，做成**可反复重跑**的环境块（而不是一次性探针）。

### 3.5 N19 `scripts/**` 的类型覆盖（489 处）
- 分布：`TS7006`（隐式 any 参数）**280** / `TS2339` 90 / `TS7031` 28 / `TS2345` 20，其余 71；
  按文件 `check-docs.mjs` 157、`measure-render.mjs` 119、`check-constants.mjs` 62、`smoke-build.mjs` 40…
- 修法：逐文件 `// @ts-check` + 补 JSDoc，**先挑"判断类"的**（`chrome-harness.mjs` / `cdp.mjs` / `check-docs.mjs`）；
- **不要**用 `noImplicitAny: false` / `strict: false` 一把放宽——那正是会漏掉 `minWorkers` 这类
  "键根本不存在"错误的开关。

### 3.6 N20 证据层非 `.md` 资产
- 形态要先分清：`before-*.xml` 一族是"**整目录即证据**"（`entry-diff.md` 成对说明）⇒ 正确形态是
  **目录级所有权**；而 `vision/*.png` 那类零引用是**真缺陷**，修法是让说明文档的**正文**链过去（C8-b 的先例）；
- 与 `evidenceRawCheck` 的 `rawOf` 同族，做时一并设计"`.md` 链接 / 索引登记 / 目录声明"各管什么。
